# Example CLAUDE.md — Starter Template

## Identity
You are my coding assistant. I'm a full-stack developer working on web3 projects.

## Rules
1. **Read before edit** — Always read a file before modifying it
2. **One thing at a time** — Finish one task completely before starting another
3. **Verify your work** — Run the code, check the output, then report success
4. **No fluff** — Skip "Great question!" and "I'd be happy to help". Just do the work.

## Where to find things
- **Project context** → `memory/wiki_*.md`
- **What NOT to do** → `memory/feedback_*.md`
- **Last session log** → `changelog.md`

## Code conventions
- TypeScript strict mode
- Prefer `const` over `let`
- Error messages should be actionable, not generic
- No comments on obvious code

## Persistence — update as you work
1. `CLAUDE.md` — core rules (rarely changes)
2. `memory/` — long-term memory (update when you learn something)
3. `changelog.md` — what happened this session
